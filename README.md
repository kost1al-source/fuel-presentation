## 🚀 Як відкрити або опублікувати на GitHub

Папка містить готову автономну веб-презентацію у стилі сучасного **Premium Dark SaaS**:
* `index.html` — головний файл презентації (автоматично відкривається на GitHub Pages).
* `prezentationforCEO.html` — пряма копія з оригінальною назвою.

Всі скріншоти та стилі **вшиті всередину HTML файлу** (Base64) — інтернет або сторонні файли для відображення не потрібні.

---

### 🌐 Публікація через GitHub Pages (за 1 хвилину):

1. Завантажте папку або весь репозиторій на **GitHub**.
2. Перейдіть у репозиторії в меню **Settings** ➔ **Pages**.
3. У розділі **Build and deployment**:
   * **Source**: `Deploy from a branch`
   * **Branch**: `main` (або `master`) ➔ папка `/presentation` (або `/root` якщо заливаєте тільки цю папку в окремий репозиторій)
4. Натисніть **Save**.
5. Через 30 секунд GitHub надасть публічне посилання на інтерактивний сайт-презентацію для відправки керівництву.
